# 税务工作台 · Python 开发版

这是独立的程序与更新包发布仓库，与原来的 e-tax-login-assistant 仓库分开维护。

## 首个独立版本：0.2.1

[下载完整程序 ZIP](https://github.com/xArsenn/tax-workbench-updates/raw/refs/heads/main/packages/tax-workbench-python-0.2.1.zip)

1. 下载后完整解压到固定文件夹，不要在压缩包内直接运行。
2. 需要 Windows、Python 3.10+（含 Tk）以及 Edge。
3. 首次使用可双击 `安装运行环境.pyw`，安装浏览器组件。
4. 双击 `启动税务登录助手.pyw` 打开软件，无需命令窗口。若文件关联未设置，可选择 Python 的 pythonw.exe 打开。
5. 软件内点击左下方“检查更新”，或“系统管理 → 软件更新”。发现新版后下载，再点击“重启并更新”。

这是 Python 开发版，不是 EXE 安装包。首次部署仍需要 Python 和运行环境。

## 本版更新

- 独立 GitHub 更新源；启动时后台检查，界面手动检查和下载。
- 发布清单使用 RSA-SHA256 签名，更新包校验 SHA256 和大小。
- 新旧版本分目录保存，完成下载后由用户重启切换。
- 新版本初始化失败时退回原工作版本（仅启动阶段，40 秒检测）。
- 税局业务窗口仍活动时阻止更新重启，避免中断业务。
- 修复后台发现新版后再打开更新窗口，下载按钮未启用的问题。
- 保留公司管理、地区网址、登录辅助和本地报表功能。

## 数据边界

本仓库及程序包不含公司档案、账号密码、财务报表、浏览器会话或发布私钥。
公司资料仍使用 Windows 当前用户的本地 ShenzhenTaxLoginManager 资料目录，不随程序更新覆盖。
换电脑不会自动同步资料，Windows 当前用户加密的密码不能直接跨用户解密。
图形验证码、短信验证等由用户完成。此版本发布不代表已经实现或验证自动报税。

## 验证范围与限制

已验证：8 项更新自动化测试，更新窗口运行与状态测试；详见验证记录。
启动失败回退测试采用模拟子进程；不等同于所有电脑的真实升级/回退测试。
未完整验证：各省真实税局登录、报送、所有电脑运行环境、财务业务计算正确性。
更新依赖 GitHub 网络可达性；暂未接入国内下载镜像。
稳定启动器和验签核心目前不自动替换，若将来升级此层需发布完整包并人工替换。
